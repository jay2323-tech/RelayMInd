# Codex work log

This folder belongs to Codex. Codex: follow the rules and entry template in
`../README.md`. Create one file per working day (`YYYY-MM-DD.md`) and append an
entry for every task you complete: what was done, how it works, what it affects,
problems found and how they were resolved, real verification results, and open
items. Do not edit `../claude/`.

Reviews count as work: when you review a branch, PR or design, log the findings,
the evidence for each, and whether they were fixed.
