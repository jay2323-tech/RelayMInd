### How it works

Preview does not call the DB or an LLM. XLSX Employees rows use stable employee
IDs and existing team IDs; unknown fields/references, duplicate IDs, formulas and
manager cycles are rejected. Python TopologicalSorter detects reporting cycles.
User must explicitly confirm synthetic data for XLSX and request --apply for a
write. Original rows are retained in a canonical immutable directory snapshot;
content changes create a different snapshot. Source file fingerprints support
provenance. Separate graph employee/team rows describe each snapshot's hierarchy.
There is no active-snapshot pointer or automatic agent-truth promotion.
